## [1.1.0] - 2026-11-23

### Added

- The original mod's Mojang Studios intro after loading: 79-frame Mojang logo, STUDIOS fade-in and the startup sound, with the original's sound synchronization (the logo holds at 350 ms until the sound starts, with an 8 s fallback). It fades in over the loading picture and fades out into the flight in that picture's place.
- Esc skips the intro and fades the startup sound.
- The opening flight dives past the finished Mojang card (generated by tools/build-intro-card.mjs), like the original outro.
- Every part of the opening can be turned off on its own. Without the flight, the intro fades straight into the menu.
- New options (configuration schema 5): `mojangLogoAnimation`, `mojangFadeIn`, `mojangCardDive`, `holdMenuMusic`, `startupSound`, `startupSoundFile`, `startupSoundVolume`, `startupSoundDelayMs` and `introFlightStartMs`. The startup sound follows the game's main and sound volume.

### Changed

- Target Minecraft Bedrock 1.26.60.05, build with LeviLamina 26.60.7, and migrate package metadata from `tooth.json` to `lip.toml` (format 4) using the default `""` client variant (`side = "client"`) and bare `github.com/LiteLDev/LeviLamina` dependency `>=26.60.8 <26.61.0`. The mod version is 1.1.0 (release tag `v1.1.0`).
- Preload textures from the frame renderer and JSON loading screen using the texture group available in Bedrock 1.26.60.05.
- Pause and resume menu music through the sound engine during the intro and startup sound.
- Limit packaged documentation to NOTICE.md, COPYING.LESSER and COPYING.txt; exclude READMEs, the changelog and the legacy CC0 LICENSE file, and remove their stale copies from build output.
- Compile with C++23 to support the LeviLamina reflection headers.

### Fixed

- Align the release tag (`v1.1.0`) with `lip.toml` `version` (`1.1.0`) so `lip install` resolves the release asset URL without a 404.
- Copy the current COPYING.LESSER and COPYING.txt license files during build and packaging instead of the removed LICENSE file.

## [1.0.0-mc26.51] - 2026-10-04

### Added

- First public Windows x64 client release for Minecraft Bedrock 1.26.51.01 and LeviLamina 26.51.6.
- A 3D cave background with baked colored lighting, animated flowing lava, wall-mounted soul torches, and flame/smoke particles.
- A loading-image-to-cave intro synchronized with the Minecraft title animation and menu fade, with Esc to skip.
- Camera views and transitions for the main menu, world list, settings, dressing room, Realms, and Marketplace.
- Resource preloading, reusable scene buffers, and bounded animation steps after rendering stalls.
- A lip v3 client package manifest, English/Chinese READMEs, and agent maintenance instructions.

### Fixed

- Straight and curved rail texture orientation and connection boundaries.
- Menu title placement below foreground controls, and camera return during UI exit transitions.

### Changed

- Release packages include runtime files and basic documentation only.
- Versions use the Playback-style `-mc26.51` compatibility suffix; the feature version is 1.0.0.

### Removed

- Unused rendering prototypes, historical backups, unused Mojang/STUDIOS animation and startup audio assets.
- Automatic texture-preload, camera-state, frame-gap, and periodic performance logs, including their diagnostic-only timers and counters.

See [README.md](https://github.com/MRUIAW/Animated-Mojang/blob/v1.0.0-mc26.51/README.md#known-limitations) for outstanding rendering details and validation limits. Native UI stalls are not claimed to be fixed.
